## 115年度速算公式（公告附件）

應納稅額＝綜合所得淨額×稅率－累進差額

| 級別 | 綜合所得淨額 | 稅率 | 累進差額 |
|---|---|---|---|
| 1 | 0～610,000 | 5% | 0 |
| 2 | 610,001～1,380,000 | 12% | 42,700 |
| 3 | 1,380,001～2,770,000 | 20% | 153,100 |
| 4 | 2,770,001～5,190,000 | 30% | 430,100 |
| 5 | 5,190,001以上 | 40% | 949,100 |

驗算：累進差額應等於「把各級距逐段累進計算」的結果。下面用程式確認公告的累進差額跟級距一致。

```python
# 參數：115年度課稅級距與速算公式（來源：[[115年度綜所稅免稅額扣除額課稅級距公告]]）
上限 = [610_000, 1_380_000, 2_770_000, 5_190_000]
稅率 = [5, 12, 20, 30, 40]          # 百分比
公告累進差額 = [0, 42_700, 153_100, 430_100, 949_100]

差額 = [0]
for i in range(1, 5):
    # 第 i 級的累進差額 = 前一級累進差額 + 前一級上限 ×（本級稅率 − 前一級稅率）
    差額.append(差額[-1] + 上限[i - 1] * (稅率[i] - 稅率[i - 1]) // 100)

for i in range(5):
    print(f"第{i+1}級 稅率{稅率[i]}%：計算 {差額[i]:,}／公告 {公告累進差額[i]:,}",
          "一致" if 差額[i] == 公告累進差額[i] else "不一致")
```
執行結果：
```text
第1級 稅率5%：計算 0／公告 0 一致
第2級 稅率12%：計算 42,700／公告 42,700 一致
第3級 稅率20%：計算 153,100／公告 153,100 一致
第4級 稅率30%：計算 430,100／公告 430,100 一致
第5級 稅率40%：計算 949,100／公告 949,100 一致
```
