# 物價指數連動調整

## 一句話重點

免稅額、課稅級距、標準扣除額、薪資和身心障礙特別扣除額，在物價累計上漲3%以上時按漲幅調整；最低稅負的金額則是10%以上才調整。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 5-1 -->
> [!quote] 法條原文｜所得稅法第5條之1（版本 115-09-11）
> 綜合所得稅之標準扣除額、薪資所得特別扣除額及身心障礙特別扣除額以第十七條規定之金額為基準，其計算調整方式，準用第五條第一項及第四項之規定。
> 前項扣除額及第五條免稅額之基準，應依所得水準及基本生活變動情形，每三年評估一次。
<!-- /law -->

（第5條第1項、第3項、第4項全文見 [[所得稅法第5條]]。）

## 入門版

- 物價漲了，同樣的錢買得到的東西變少。為了不讓大家因為通膨多繳稅，有些金額會跟著物價調整。
- **門檻**：跟「上次調整那一年」比，物價累計漲了**3%以上**才調整。沒到3%就維持原金額。
- 115年度：跟113年度比上漲4.13%，所以調整（[[115年度綜所稅免稅額扣除額課稅級距公告]]）。

例外情形見進階版。

## 進階版

| 項目 | 門檻 | 進位方式 | 法源 |
|---|---|---|---|
| 免稅額 | 3% | 以千元為單位，未達千元按百元數四捨五入 | 第5條第1項 |
| 課稅級距 | 3% | 以萬元為單位，未達萬元按千元數四捨五入 | 第5條第3項 |
| 標準扣除額、薪資所得特別扣除額、身心障礙特別扣除額 | 準用第5條第1項 | 準用第5條第1項 | 第5條之1第1項 |
| 所得基本稅額條例的金額 | 10% | — | 依公告說明（條例原文本頁未引用） |

- 消費者物價指數：行政院主計總處公布至上年度十月底為止十二個月的平均（第5條第4項）。
- 第5條之1第2項：扣除額及免稅額的基準，每三年依所得水準及基本生活變動情形評估一次。

## 計算例題

**入門題**：上次調整後的免稅額是 97,000 元，物價累計上漲 2.5%。要調整嗎？

```python
上漲 = 2.5
print("達3%，應調整" if 上漲 >= 3 else "未達3%，不調整")
```
執行結果：
```text
未達3%，不調整
```

**進階題（一致性驗算）**：把113年度調整後的金額乘上 1.0413（公告的上漲幅度 4.13%），依第5條的進位規則處理，看結果是否與115年度公告金額一致。

> [!note] 本 wiki 整理
> 這是**一致性檢查**，不是財政部的計算方法：法條規定以「上次調整年度之指數」比較上漲程度，財政部實際如何從基準金額計算，公告中沒有寫明。本題只確認公告數字與4.13%的漲幅、進位規則相符。

```python
from decimal import Decimal, ROUND_HALF_UP

漲幅 = Decimal("1.0413")
def 千元(x):   # 以千元為單位，未達千元者按百元數四捨五入
    return int((Decimal(x) * 漲幅 / 1000).quantize(Decimal("1"), rounding=ROUND_HALF_UP) * 1000)
def 萬元(x):   # 以萬元為單位，未達萬元者按千元數四捨五入
    return int((Decimal(x) * 漲幅 / 10000).quantize(Decimal("1"), rounding=ROUND_HALF_UP) * 10000)

# (項目, 113年度調整後金額, 115年度公告金額, 進位方式) —— 來源：[[綜合所得稅免稅額扣除額與課稅級距]]
資料 = [
    ("免稅額", 97_000, 101_000, 千元),
    ("標準扣除額（單身）", 131_000, 136_000, 千元),
    ("薪資所得特別扣除額", 218_000, 227_000, 千元),
    ("身心障礙特別扣除額", 218_000, 227_000, 千元),
    ("5%級距上限", 590_000, 610_000, 萬元),
    ("12%級距上限", 1_330_000, 1_380_000, 萬元),
    ("20%級距上限", 2_660_000, 2_770_000, 萬元),
    ("30%級距上限", 4_980_000, 5_190_000, 萬元),
]
for 項目, 前, 公告, 進位 in 資料:
    算 = 進位(前)
    print(f"{項目}：{前:,} × 1.0413 → {算:,}；公告 {公告:,}；{'一致' if 算 == 公告 else '不一致'}")
```
執行結果：
```text
免稅額：97,000 × 1.0413 → 101,000；公告 101,000；一致
標準扣除額（單身）：131,000 × 1.0413 → 136,000；公告 136,000；一致
薪資所得特別扣除額：218,000 × 1.0413 → 227,000；公告 227,000；一致
身心障礙特別扣除額：218,000 × 1.0413 → 227,000；公告 227,000；一致
5%級距上限：590,000 × 1.0413 → 610,000；公告 610,000；一致
12%級距上限：1,330,000 × 1.0413 → 1,380,000；公告 1,380,000；一致
20%級距上限：2,660,000 × 1.0413 → 2,770,000；公告 2,770,000；一致
30%級距上限：4,980,000 × 1.0413 → 5,190,000；公告 5,190,000；一致
```

## 常見誤解

- ❌「每年都會調整」→ 累計漲幅達3%才調整。114年度是否調整，本 wiki 尚未匯入114年度公告。
- ❌「所有扣除額都會隨物價調整」→ 只有第5條之1列的三項（加上第5條的免稅額、級距）；房屋租金、幼兒學前等是固定金額。
