# 持有期間

## 一句話重點

持有期間從「取得日」算到「交易日」，兩者原則上都是完成所有權移轉登記日；持有越久，房地合一稅率越低。

## 入門版

- **取得日**：買進那間房子完成過戶登記的日子。
- **交易日**：賣出那間房子完成過戶登記的日子。
- **持有期間** = 從取得日到交易日。
- **例外**：預售屋看簽約日；繼承的房子可以把過世親人的持有期間加進來；配偶贈與的也可以合併計算。

稅率對照見 [[房地合一稅率]]。例外情形見進階版。

## 進階版

> [!info] 官方解釋｜房地合一課徵所得稅申報作業要點第五點第一項序文（115年4月21日修正）
> 五、第三點房屋、土地、房屋使用權、預售房地、符合一定條件股份或出資額持有期間之計算，自前點其取得之日起算至第三點交易之日止。但有下列情形，其持有期間得依各款規定合併計算：

**交易日與取得日（作業要點第三點、第四點）**

| 標的 | 交易日 | 取得日 |
|---|---|---|
| 房屋、土地 | 完成所有權移轉登記日 | 完成所有權移轉登記日 |
| 房屋使用權 | 權利移轉之日 | 權利移轉之日 |
| 預售房地 | 訂定買賣契約之日 | 訂定買賣契約之日 |
| 股份或出資額（有價證券） | 買賣交割日 | 買賣交割日 |

第四點另列十七種特殊取得日，例如：興建房屋完成後第一次移轉以核發使用執照日為準、繼承取得以繼承開始日為準、配偶贈與取得以配偶原始取得之日為準。

**合併計算（作業要點第五點；所得稅法第14條之4第4項）**
- 繼承、受遺贈：得併計被繼承人、遺贈人的持有期間；連續繼承可連續併計。
- 配偶贈與：得併計配偶的持有期間。
- 用於自住免稅（第4條之5第1項第1款）時，併計的期間另須符合辦竣戶籍登記並居住、無出租或營業使用。

## 計算例題

**入門題**：房屋於112年3月1日完成移轉登記取得，115年5月20日完成移轉登記出售。持有期間多久？境內居住者適用哪一級稅率？

```python
from datetime import date

取得日 = date(2023, 3, 1)      # 民國112年3月1日
交易日 = date(2026, 5, 20)     # 民國115年5月20日

def 加年(d, n):
    return d.replace(year=d.year + n)

if 交易日 <= 加年(取得日, 2):
    級 = "二年以內：45%"
elif 交易日 <= 加年(取得日, 5):
    級 = "超過二年，未逾五年：35%"
elif 交易日 <= 加年(取得日, 10):
    級 = "超過五年，未逾十年：20%"
else:
    級 = "超過十年：15%"
print(f"持有 {(交易日 - 取得日).days} 天 → {級}")
```
執行結果：
```text
持有 1176 天 → 超過二年，未逾五年：35%
```

**進階題**：父親於103年8月1日取得房屋（房地合一施行前），本人於113年2月1日繼承（繼承開始日），115年9月1日出售。依作業要點第五點併計後，持有期間屬哪一級？

```python
from datetime import date

父親取得日 = date(2014, 8, 1)    # 民國103年8月1日
交易日 = date(2026, 9, 1)        # 民國115年9月1日
十年後 = 父親取得日.replace(year=父親取得日.year + 10)
print(f"併計後持有 {(交易日 - 父親取得日).days} 天；",
      "超過十年：15%" if 交易日 > 十年後 else "未逾十年")
```
執行結果：
```text
併計後持有 4414 天； 超過十年：15%
```

> [!info] 官方解釋｜房地合一課徵所得稅申報作業要點第四點第十四款（115年4月21日修正）
> (十四)繼承取得之房屋、土地、房屋使用權、預售房地、股份或出資額，為繼承開始日。

> [!note] 本 wiki 整理
> 依上述規定，本題繼承人的取得日為113年2月1日（繼承開始日），在105年1月1日以後，所以出售時適用房地合一（[[所得稅法第4條之4]]）；計算**持有期間**時，再依作業要點第五點第一項第一款併計父親的持有期間。「取得日」與「持有期間起算」是兩件事，教學時要分開講。

## 常見誤解

- ❌「從簽約日算到簽約日」→ 房屋、土地原則上都看完成所有權移轉登記日。
- ❌「繼承的房子要從繼承那天重新算」→ 可以併計被繼承人的持有期間（第14條之4第4項、作業要點第五點）。
