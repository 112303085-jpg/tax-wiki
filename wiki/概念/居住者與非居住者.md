# 居住者與非居住者

## 一句話重點

在臺灣有住所並經常居住，或一個課稅年度內在臺居留合計滿183天，就是「中華民國境內居住之個人」；其他人是非居住者。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 7 -->
> [!quote] 法條原文｜所得稅法第7條（版本 115-09-11）
> 本法稱人，係指自然人及法人。本法稱個人，係指自然人。
> 本法稱中華民國境內居住之個人，指左列兩種：
> 一、在中華民國境內有住所，並經常居住中華民國境內者。
> 二、在中華民國境內無住所，而於一課稅年度內在中華民國境內居留合計滿一百八十三天者。
> 本法稱非中華民國境內居住之個人，係指前項規定以外之個人。
> 本法稱納稅義務人，係指依本法規定，應申報或繳納所得稅之人。
> 本法稱扣繳義務人，係指依本法規定，應自付與納稅義務人之給付中扣繳所得稅款之人。
<!-- /law -->

<!-- law: raw/A_法規/1150911_所得稅法.md | 2 -->
> [!quote] 法條原文｜所得稅法第2條（版本 115-09-11）
> 凡有中華民國來源所得之個人，應就其中華民國來源之所得，依本法規定，課徵綜合所得稅。
> 非中華民國境內居住之個人，而有中華民國來源所得者，除本法另有規定外，其應納稅額，分別就源扣繳。
<!-- /law -->

## 入門版

符合下面任一種，就是稅法上的「境內居住者」：
1. 在臺灣**有住所**，而且**經常住在臺灣**。
2. 在臺灣**沒有住所**，但**一個課稅年度內在臺灣居留合計滿183天**（不必連續）。

身分不同，課稅方式不同：
- 綜所稅：非居住者有中華民國來源所得，原則上「就源扣繳」（第2條第2項）。
- 房地合一：持有2年以內，兩者都是45%；持有超過2年未逾5年，兩者都是35%；持有超過5年，居住者降到20%、15%，非居住者仍是35%（見 [[房地合一稅率]]）。

例外情形見進階版。

## 進階版

- 第7條第2項第1款「有住所並經常居住」的具體認定標準，第7條本身沒有規定，已匯入的來源中也沒有。
- 第7條第2項第2款的183天是「一課稅年度內」「居留合計」，不必連續。
- 房地合一的稅率依[[所得稅法第14條之4]]第3項第1款（境內居住之個人）與第2款（非境內居住之個人）區分。

## 計算例題

**入門題**：一位外籍人士在臺灣沒有住所，115年度分三次來臺，分別停留 60、70、55 天。是否為境內居住之個人？

```python
停留天數 = [60, 70, 55]
合計 = sum(停留天數)
print(f"合計 {合計} 天 →", "境內居住之個人" if 合計 >= 183 else "非境內居住之個人")
```
執行結果：
```text
合計 185 天 → 境內居住之個人
```

**進階題**：同一人若出售持有3年的房屋，課稅餘額 2,000,000 元，身分不同時稅額差多少？（稅率：[[房地合一稅率]]）

```python
餘額 = 2_000_000
居住者稅率, 非居住者稅率 = 35, 35        # 持有超過2年未逾5年：兩者皆35%
print(f"持有3年：居住者 {餘額*居住者稅率//100:,} 元；非居住者 {餘額*非居住者稅率//100:,} 元")

居住者稅率, 非居住者稅率 = 20, 35        # 持有超過5年未逾10年：居住者20%；非居住者超過2年一律35%
print(f"持有7年：居住者 {餘額*居住者稅率//100:,} 元；非居住者 {餘額*非居住者稅率//100:,} 元")
```
執行結果：
```text
持有3年：居住者 700,000 元；非居住者 700,000 元
持有7年：居住者 400,000 元；非居住者 700,000 元
```

## 常見誤解

- ❌「183天要連續」→ 條文是「居留合計」。
- ❌「有臺灣國籍就是居住者」→ 第7條看的是住所與居留天數，不是國籍。
