# 房地合一所得稅

## 一句話重點

105年1月1日以後取得的房屋、土地，出售時以實際獲利計稅，依持有期間適用45%～15%的稅率，和綜所稅分開計算、在過戶後30日內申報。

## 進階版

- **視同房地交易**：房屋使用權、預售房地、符合一定條件的股份或出資額（第4條之4第2項、第3項；作業要點第二點、第六點）。
- **特別稅率**：非自願因素、合建、都更危老、自住超過400萬元部分（第14條之4第3項第1款第5目至第8目）。
- **損失**：三年內可自房地合一所得減除，但不能和綜所稅的財產交易損失互抵（作業要點第十八點）。
- **核定**：未申報或價格偏低，稽徵機關得依時價核定；費用未提示按成交價額3%、上限30萬元（第14條之6、第14條之7）。
- **營利事業**：第24條之5，第一階段不展開。
- **舊制**：105年以前取得的房屋出售時，依所得稅法第14條第1項第7類財產交易所得併入綜所稅（施行細則第17條之2），本 wiki 尚未建頁。

## 計算例題

**入門題**：境內居住者，112年3月1日登記取得、115年5月20日登記出售（持有超過2年未逾5年）。買價 10,000,000 元、賣價 13,000,000 元，未提示費用證明，土地漲價總數額 500,000 元。應納稅額？

```python
賣價, 成本, 土地漲價總數額 = 13_000_000, 10_000_000, 500_000
費用 = min(賣價 * 3 // 100, 300_000)      # 第14條之6：未提示費用證明，按3%、上限30萬
稅率 = 35                                   # 持有超過2年未逾5年（[[持有期間]] 例題）

餘額 = 賣價 - 成本 - 費用 - 土地漲價總數額
print(f"費用 {費用:,}；餘額 {餘額:,}；應納稅額 {餘額 * 稅率 // 100:,} 元")
```
執行結果：
```text
費用 300,000；餘額 2,200,000；應納稅額 770,000 元
```

**進階題**：符合自住要件（第4條之5第1項第1款），賣價 25,000,000 元、成本 18,000,000 元、提示費用 500,000 元、土地漲價總數額 1,000,000 元。應納稅額？

```python
賣價, 成本, 費用, 土地漲價總數額 = 25_000_000, 18_000_000, 500_000, 1_000_000
餘額 = 賣價 - 成本 - 費用 - 土地漲價總數額
應稅 = max(餘額 - 4_000_000, 0)              # 400萬以內免稅（第4條之5）
print(f"餘額 {餘額:,}；免稅 {min(餘額, 4_000_000):,}；應稅 {應稅:,}；應納稅額 {應稅 * 10 // 100:,} 元")
```
執行結果：
```text
餘額 5,500,000；免稅 4,000,000；應稅 1,500,000；應納稅額 150,000 元
```

## 常見誤解

- ❌「賣房子賺錢併入綜所稅」→ 新制分開計稅、單獨申報。
- ❌「沒賺錢不用報」→ 不論有無應納稅額都要報（自住免稅也要報）。
- ❌「持有期間從簽約日算」→ 原則上看完成所有權移轉登記日。
