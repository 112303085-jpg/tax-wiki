# 綜合所得稅

## 一句話重點

個人一年的各類所得合併起來，扣掉免稅額和扣除額得到所得淨額，再按5%～40%累進稅率計稅，每年5月申報上一年度的所得。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 71 -->
> [!quote] 法條原文｜所得稅法第71條（版本 115-09-11）
> 納稅義務人應於每年五月一日起至五月三十一日止，填具結算申報書，向該管稽徵機關，申報其上一年度內構成綜合所得總額或營利事業收入總額之項目及數額，以及有關減免、扣除之事實，並應依其全年應納稅額減除暫繳稅額、尚未抵繳之扣繳稅額及依第十五條第四項規定計算之可抵減稅額，計算其應納之結算稅額，於申報前自行繳納。但依法不併計課稅之所得之扣繳稅款，不得減除。
> 獨資、合夥組織之營利事業應依前項規定辦理結算申報，無須計算及繳納其應納之結算稅額；其營利事業所得額，應由獨資資本主或合夥組織合夥人依第十四條第一項第一類規定列為營利所得，依本法規定課徵綜合所得稅。但其為小規模營利事業者，無須辦理結算申報，由稽徵機關核定其營利事業所得額，直接歸併獨資資本主或合夥組織合夥人之營利所得，依本法規定課徵綜合所得稅。
> 中華民國境內居住之個人全年綜合所得總額不超過當年度規定之免稅額及標準扣除額之合計數者，得免辦理結算申報。但申請退還扣繳稅款及第十五條第四項規定之可抵減稅額，或依第十五條第五項規定課稅者，仍應辦理結算申報。

## 入門版

**一張圖看懂綜所稅**

1. **所得總額**：薪資、利息、股利、租金等各類所得加總（第14條）。
2. **減免稅額**：每人一份；年滿70歲的本人、配偶及受扶養直系尊親屬多50%，115年度起受扶養的未成年子女也多50%（第17條）。
3. **減扣除額**：標準或列舉二選一，再加特別扣除額（第17條）。
4. **= 所得淨額**
5. **× 稅率 − 累進差額 = 應納稅額**（第5條；115年度速算公式見 [[綜合所得稅免稅額扣除額與課稅級距]]）
6. **申報**：每年5月1日至5月31日，申報**上一年度**的所得（第71條）。115年度所得在116年5月申報。

**誰要報**：有中華民國來源所得的個人（第2條）。本人、配偶和受扶養親屬原則上**合併申報**（第15條）。

例外情形見進階版。

## 進階版

- **非居住者**：有中華民國來源所得者，原則上就源扣繳（第2條第2項），見 [[居住者與非居住者]]。
- **合併申報**：第15條規定納稅義務人、配偶及受扶養親屬合併申報及計算稅額；分居者得各自申報。分居的認定要件及應檢附之證明文件由財政部定之（第15條第3項），本 wiki 尚未匯入該規定。
- **房地合一不併入**：個人房地交易所得依第14條之4分開計稅，不併計綜合所得總額，見 [[房地合一所得稅]]。
- **最低稅負制**：依所得基本稅額條例，基本所得額扣除115年度750萬元後按20%計算基本稅額，再與一般所得稅額比較（條例第4條、第13條；[[所得基本稅額條例]]）。
- **長照、租金扣除的排除條件**：適用稅率20%以上、股利選擇28%分開計稅、基本所得額超過扣除金額者，不得適用（第17條第3項）。

## 計算例題

**入門題**：115年度，單身、薪資 800,000 元、無扶養、選標準扣除額。應納稅額多少？（參數：[[綜合所得稅免稅額扣除額與課稅級距]]，115年度）

```python
# 115年度參數
免稅額, 標準扣除額, 薪資特扣 = 101_000, 136_000, 227_000
級距 = [(610_000, 5, 0), (1_380_000, 12, 42_700), (2_770_000, 20, 153_100),
        (5_190_000, 30, 430_100), (float("inf"), 40, 949_100)]

薪資 = 800_000
淨額 = max(薪資 - 免稅額 - 標準扣除額 - min(薪資, 薪資特扣), 0)
for 上限, 率, 差額 in 級距:
    if 淨額 <= 上限:
        稅額 = 淨額 * 率 // 100 - 差額
        break
print(f"所得淨額 {淨額:,} 元；應納稅額 {稅額:,} 元")
```
執行結果：
```text
所得淨額 336,000 元；應納稅額 16,800 元
```

**進階題**：驗算財政部公告中的「租屋自住之單身上班族年薪64.4萬元……可免繳所得稅」。假設全年房租至少18萬元、未受政府補助、在境內沒有房屋、不適用第17條第3項的排除條件。

```python
# 115年度參數（[[綜合所得稅免稅額扣除額與課稅級距]]）；房屋租金特別扣除上限為第17條第1項第2款第3目之8的固定金額
免稅額, 標準扣除額, 薪資特扣, 租金特扣上限 = 101_000, 136_000, 227_000, 180_000
年薪 = 644_000
房租 = 180_000

淨額 = 年薪 - 免稅額 - 標準扣除額 - min(年薪, 薪資特扣) - min(房租, 租金特扣上限)
print(f"所得淨額 {淨額:,} 元 →", "免繳所得稅" if 淨額 <= 0 else "需繳稅")
```
執行結果：
```text
所得淨額 0 元 → 免繳所得稅
```

## 常見誤解

- ❌「5月報的是今年的所得」→ 是上一年度的所得（第71條）。
- ❌「免稅額是6萬元」→ 那是法定基準，115年度是101,000元（見 [[所得稅法第5條]]）。
- ❌「最低稅負制扣除600萬元」→ 條例第13條寫600萬元，但115年度公告的個人免稅額度是750萬元。
- ❌「賣房子賺的錢要併入綜所稅」→ 房地合一新制的所得分開計稅。
