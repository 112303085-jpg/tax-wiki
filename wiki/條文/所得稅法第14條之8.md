# 所得稅法第14條之8（重購自住房地退稅或扣抵）

## 一句話重點

賣掉自住房地繳了房地合一稅，兩年內再買自住房地，可以按「重購價額 ÷ 出售價額」的比率退稅；先買後賣也可以扣抵。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 14-8 -->
> [!quote] 法條原文｜所得稅法第14條之8（版本 115-09-11）
> 個人出售自住房屋、土地依第十四條之五規定繳納之稅額，自完成移轉登記之日或房屋使用權交易之日起算二年內，重購自住房屋、土地者，得於重購自住房屋、土地完成移轉登記或房屋使用權交易之次日起算五年內，申請按重購價額占出售價額之比率，自前開繳納稅額計算退還。
> 個人於先購買自住房屋、土地後，自完成移轉登記之日或房屋使用權交易之日起算二年內，出售其他自住房屋、土地者，於依第十四條之五規定申報時，得按前項規定之比率計算扣抵稅額，在不超過應納稅額之限額內減除之。
> 前二項重購之自住房屋、土地，於重購後五年內改作其他用途或再行移轉時，應追繳原扣抵或退還稅額。
<!-- /law -->

## 入門版

- **先賣後買**：賣掉自住房子並繳稅後，**兩年內**再買自住房子，可以在新房子過戶次日起**五年內**申請退稅。
- **先買後賣**：先買了自住房子，**兩年內**再賣掉另一間自住房子，申報時可以直接扣抵。
- **退多少**：按「重購價額占出售價額的比率」計算。
- **注意**：重購後**五年內**改作其他用途或再賣掉，退掉的稅要追繳。

例外情形見進階版。

## 進階版

**作業要點的補充**

> [!info] 官方解釋｜房地合一課徵所得稅申報作業要點第二十點（115年4月21日修正）
> 二十、本法第十四條之八有關自住房屋、土地、房屋使用權交易所得稅額扣抵及退還之規定，個人或其配偶、未成年子女應於該出售及購買之房屋、房屋使用權辦竣戶籍登記並實際居住，且該等房屋、房屋使用權無出租、供營業或執行業務使用；以配偶之一方出售自住房屋、土地、房屋使用權，而以配偶之他方名義重購者，亦得適用。

**考點**
- 「自住」在本條的意義由作業要點第二十點補充：出售及購買的房屋都要辦竣戶籍登記並實際居住，且無出租、營業使用。
- 夫妻一方賣、另一方買，也可以適用。
- 本條和[[所得稅法第4條之5]]的「自住房地免稅」是兩個不同制度：前者是退稅，後者是免稅額度。

## 計算例題

**入門題**：出售自住房屋 20,000,000 元，已繳房地合一稅 400,000 元；一年後重購自住房屋 15,000,000 元。可退多少？

```python
出售價額 = 20_000_000
已繳稅額 = 400_000
重購價額 = 15_000_000

比率 = 重購價額 / 出售價額
退稅 = round(已繳稅額 * 比率)
print(f"比率 {比率:.0%}；可退稅額 {退稅:,} 元")
```
執行結果：
```text
比率 75%；可退稅額 300,000 元
```

**進階題**：先買後賣。先購自住房屋 12,000,000 元，一年後出售另一間自住房屋 16,000,000 元，該筆交易應納稅額 300,000 元。申報時可扣抵多少？

```python
出售價額 = 16_000_000
重購價額 = 12_000_000          # 先購買的自住房屋
應納稅額 = 300_000

扣抵 = round(應納稅額 * 重購價額 / 出售價額)
扣抵 = min(扣抵, 應納稅額)        # 第2項：不超過應納稅額之限額
print(f"可扣抵 {扣抵:,} 元；扣抵後應納 {應納稅額 - 扣抵:,} 元")
```
執行結果：
```text
可扣抵 225,000 元；扣抵後應納 75,000 元
```

## 常見誤解

- ❌「重購就能全額退稅」→ 按重購價額占出售價額的比率計算。
- ❌「退稅後就沒事了」→ 重購後五年內改作其他用途或再行移轉，要追繳。
