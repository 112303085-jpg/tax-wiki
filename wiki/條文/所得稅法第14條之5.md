# 所得稅法第14條之5（個人房地合一的申報期限）

## 一句話重點

不論有沒有賺錢，都要在完成所有權移轉登記日的次日起算30日內申報。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 14-5 -->
> [!quote] 法條原文｜所得稅法第14條之5（版本 115-09-11）
> 個人有前條之交易所得或損失，不論有無應納稅額，應於下列各款規定日期起算三十日內自行填具申報書，檢附契約書影本及其他有關文件，向該管稽徵機關辦理申報；其有應納稅額者，應一併檢附繳納收據：
> 一、第四條之四第一項所定房屋、土地完成所有權移轉登記日之次日。
> 二、第四條之四第二項所定房屋使用權交易日之次日、預售屋及其坐落基地交易日之次日。
> 三、第四條之四第三項所定股份或出資額交易日之次日。
<!-- /law -->

## 入門版

- **有賠錢也要報**：條文寫「不論有無應納稅額」。
- **期限**：房屋、土地是從「完成所有權移轉登記日的次日」開始算30天；預售屋、房屋使用權、股份則從交易日的次日開始算。
- **要附什麼**：申報書、契約書影本、其他文件；有稅要繳的，附繳納收據。
- **向哪裡報**：原則上是申報時戶籍所在地的國稅局（作業要點第十點）。

例外情形見進階版。

## 進階版

**作業要點的補充**
- 第九點：第4條之5第1項第2款至第4款（農地、徵收、公設保留地）、合建分屋以地易屋、參與都更或危老重建以地換屋等情形，免辦申報。
- 第十點：管轄稽徵機關的順序為戶籍所在地 → 居留地 → 房地所在地（股份為所屬國內營利事業所在地）→ 中央政府所在地。
- 第二十八點：逾期繳納者依所得稅法第112條加徵滯納金及移送強制執行。

**考點**：起算日是「次日」，不是登記當天。

## 計算例題

**入門題**：房屋在115年3月10日完成所有權移轉登記，申報期限的最後一天是哪一天？

```python
from datetime import date, timedelta

登記日 = date(2026, 3, 10)                 # 民國115年3月10日
起算日 = 登記日 + timedelta(days=1)         # 次日起算
最後一日 = 起算日 + timedelta(days=29)      # 起算日為第1日，共30日
print(f"起算日：{起算日.year-1911}年{起算日.month}月{起算日.day}日；"
      f"第30日：{最後一日.year-1911}年{最後一日.month}月{最後一日.day}日")
```
執行結果：
```text
起算日：115年3月11日；第30日：115年4月9日
```

**進階題**：預售屋在115年12月20日簽訂買賣契約（交易日），申報期限的最後一天？

```python
from datetime import date, timedelta

交易日 = date(2026, 12, 20)                # 民國115年12月20日；預售房地以訂約日為交易日（作業要點第三點）
最後一日 = 交易日 + timedelta(days=1) + timedelta(days=29)
print(f"第30日：{最後一日.year-1911}年{最後一日.month}月{最後一日.day}日")
```
執行結果：
```text
第30日：116年1月19日
```

## 常見誤解

- ❌「沒賺錢不用報」→ 不論有無應納稅額都要申報。
- ❌「從簽約日開始算」→ 房屋、土地從完成所有權移轉登記日的次日起算；預售屋才看交易日（訂約日）。
