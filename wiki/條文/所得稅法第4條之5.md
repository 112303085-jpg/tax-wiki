# 所得稅法第4條之5（房地合一的免稅情形）

## 一句話重點

自住房地符合「設籍、持有並居住連續滿六年」等條件，所得在400萬元以內免稅；另有農地、徵收、公共設施保留地三種免稅情形。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 4-5 -->
> [!quote] 法條原文｜所得稅法第4條之5（版本 115-09-11）
> 前條交易之房屋、土地有下列情形之一者，免納所得稅。但符合第一款規定者，其免稅所得額，以按第十四條之四第三項規定計算之餘額不超過四百萬元為限：
> 一、個人與其配偶及未成年子女符合下列各目規定之自住房屋、土地：
> （一）個人或其配偶、未成年子女辦竣戶籍登記、持有並居住於該房屋連續滿六年。
> （二）交易前六年內，無出租、供營業或執行業務使用。
> （三）個人與其配偶及未成年子女於交易前六年內未曾適用本款規定。
> 二、符合農業發展條例第三十七條及第三十八條之一規定得申請不課徵土地增值稅之土地。
> 三、被徵收或被徵收前先行協議價購之土地及其土地改良物。
> 四、尚未被徵收前移轉依都市計畫法指定之公共設施保留地。
> 前項第二款至第四款規定之土地、土地改良物，不適用第十四條之五規定；其有交易損失者，不適用第十四條之四第二項損失減除、第二十四條之五第三項損失減除及同條第四項後段自營利事業所得額中減除之規定。
<!-- /law -->

## 入門版

**自住房地免稅**要同時符合三個條件：
1. 本人、配偶或未成年子女在這間房子**辦好戶籍登記**，並且**持有又住滿連續六年**。
2. 賣之前六年內，**沒有出租、營業或執行業務使用**。
3. 本人、配偶、未成年子女在賣之前六年內，**沒用過**這個自住優惠。

符合的話，所得在400萬元以內免稅；超過400萬元的部分，按10%課稅（見 [[所得稅法第14條之4]]）。

例外情形見進階版。

## 進階版

**條文結構**
- 第1項第1款：自住房地（三目要件，缺一不可）；但書：免稅所得額以按第14條之4第3項計算之餘額不超過四百萬元為限。
- 第1項第2款至第4款：農業用地（農業發展條例第37條、第38條之1）、被徵收或協議價購之土地及土地改良物、公共設施保留地。
- 第2項：第2款至第4款不適用第14條之5申報規定；有損失者不得減除。

**作業要點的補充**
- 第九點第一款：第4條之5第1項第2款至第4款的情形免辦申報。
- 第十七點：符合分居認定標準、可各自辦理結算申報的夫妻，「交易前六年內未曾適用」可以個別認定。
- 第五點：繼承、配偶贈與取得時，自住的持有期間合併計算有附加條件（須已辦竣戶籍登記並居住，且無出租、供營業或執行業務使用）。

**考點**
- 自住免稅**仍須申報**（第2項只排除第2款至第4款）。
- 400萬元是「依第14條之4第3項計算之餘額」，也就是已經減除土地漲價總數額之後的金額。

## 計算例題

**入門題**：小美的房子持有並設籍居住滿7年、沒出租、6年內沒用過自住優惠。是否符合第1項第1款？

```python
設籍持有居住年數 = 7
六年內出租營業 = False
六年內曾適用 = False

符合 = 設籍持有居住年數 >= 6 and not 六年內出租營業 and not 六年內曾適用
print("符合自住房地免稅要件" if 符合 else "不符合")
```
執行結果：
```text
符合自住房地免稅要件
```

**進階題**：符合自住要件，按第14條之4第3項計算的餘額為 5,500,000 元。免稅部分和應納稅額各多少？（稅率來源：[[房地合一稅率]]）

```python
餘額 = 5_500_000
免稅上限 = 4_000_000      # 第4條之5第1項但書
超過部分稅率 = 10         # 第14條之4第3項第1款第8目

免稅部分 = min(餘額, 免稅上限)
應稅部分 = 餘額 - 免稅部分
稅額 = 應稅部分 * 超過部分稅率 // 100
print(f"免稅部分：{免稅部分:,} 元；應稅部分：{應稅部分:,} 元；應納稅額：{稅額:,} 元")
```
執行結果：
```text
免稅部分：4,000,000 元；應稅部分：1,500,000 元；應納稅額：150,000 元
```

## 常見誤解

- ❌「自住免稅就不用申報」→ 第2項只讓第2款至第4款免申報；自住房地仍須依第14條之5申報（作業要點第九點）。
- ❌「住滿六年就好」→ 還要設籍、六年內沒出租營業、六年內沒用過，三項同時成立。
- ❌「400萬元是賣價或獲利」→ 是減除成本、費用及土地漲價總數額後的餘額。
