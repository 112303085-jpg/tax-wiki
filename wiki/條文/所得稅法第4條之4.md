# 所得稅法第4條之4（房地合一的適用範圍）

## 一句話重點

105年1月1日以後取得的房屋、土地，賣掉時的所得要依房地合一規定課稅；房屋使用權、預售屋、符合條件的股份也比照辦理。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 4-4 -->
> [!quote] 法條原文｜所得稅法第4條之4（版本 115-09-11）
> 個人及營利事業交易中華民國一百零五年一月一日以後取得之房屋、房屋及其坐落基地或依法得核發建造執照之土地（以下合稱房屋、土地），其交易所得應依第十四條之四至第十四條之八及第二十四條之五規定課徵所得稅。
> 個人及營利事業於中華民國一百零五年一月一日以後取得以設定地上權方式之房屋使用權或預售屋及其坐落基地，其交易視同前項之房屋、土地交易。
> 個人及營利事業交易其直接或間接持有股份或出資額過半數之國內外營利事業之股份或出資額，該營利事業股權或出資額之價值百分之五十以上係由中華民國境內之房屋、土地所構成者，該交易視同第一項房屋、土地交易。但交易之股份屬上市、上櫃及興櫃公司之股票者，不適用之。
> 第一項規定之土地，不適用第四條第一項第十六款規定；同項所定房屋之範圍，不包括依農業發展條例申請興建之農舍。
<!-- /law -->

## 入門版

- 判斷要不要適用房地合一，第一步看**取得日**：105年1月1日以後買（或取得）的房屋、土地，出售時適用房地合一。
- 預售屋、以設定地上權方式取得的房屋使用權，105年1月1日以後取得的，也算房地合一的交易。
- 取得日原則上是「完成所有權移轉登記日」，不是簽約日（預售房地除外；作業要點第四點），見 [[持有期間]]。

例外情形見進階版。

## 進階版

**條文結構**
- 第1項：個人及營利事業交易105年1月1日以後取得之房屋、房屋及其坐落基地或依法得核發建造執照之土地，依第14條之4至第14條之8、第24條之5課稅。
- 第2項：105年1月1日以後取得之「以設定地上權方式之房屋使用權」或「預售屋及其坐落基地」，視同房屋、土地交易。
- 第3項：交易直接或間接持有過半數之國內外營利事業股份或出資額，且該營利事業股權價值50%以上由境內房屋、土地構成者，視同房屋、土地交易；上市、上櫃及興櫃股票除外。
- 第4項：第1項的土地不適用第4條第1項第16款；房屋不包括依農業發展條例申請興建之農舍。

**作業要點的補充**

> [!info] 官方解釋｜房地合一課徵所得稅申報作業要點第四點（115年4月21日修正）
> 四、前點房屋、土地取得日之認定，以完成所有權移轉登記日為準；房屋使用權取得日之認定，以權利移轉之日為準；預售房地取得日之認定，以訂定買賣契約之日為準；股份或出資額取得日之認定，屬證券交易稅條例所稱有價證券者，以買賣交割日為準，屬上開有價證券以外者，以訂定買賣契約之日為準。但有下列情形之一者，依其規定：

> [!note] 本 wiki 整理
> 上面引文之後，第四點另列十七款例外，例如：因強制執行取得者為拍定人領得權利移轉證書之日；興建房屋完成後第一次移轉為核發使用執照日；繼承取得者為繼承開始日；配偶相互贈與者為第一次相互贈與前配偶原始取得之日。完整內容見 [[房地合一課徵所得稅申報作業要點]]。「交易日」的認定另見作業要點第三點。

**考點**：第3項「過半數」與「50%以上」是兩個不同門檻——前者看持股比例，後者看被投資事業的資產組成。作業要點第六點規定「過半數」以交易日起算前一年內任一日持股超過50%認定。

## 計算例題

本條是適用範圍的判斷，沒有金額計算；以下用程式做「新舊制判斷」。

**入門題**：房屋於104年12月20日完成移轉登記取得，另一間於105年1月5日完成移轉登記取得，各自出售時是否適用第4條之4第1項？

```python
from datetime import date

基準日 = date(2016, 1, 1)          # 民國105年1月1日
def 民國(y, m, d):
    return date(y + 1911, m, d)

for 名稱, 取得日 in [("甲屋", 民國(104, 12, 20)), ("乙屋", 民國(105, 1, 5))]:
    適用 = 取得日 >= 基準日
    print(f"{名稱}：取得日 {取得日.year - 1911}年{取得日.month}月{取得日.day}日 →",
          "適用房地合一" if 適用 else "不適用第4條之4第1項")
```
執行結果：
```text
甲屋：取得日 104年12月20日 → 不適用第4條之4第1項
乙屋：取得日 105年1月5日 → 適用房地合一
```

**進階題**：個人出售未上市公司股份，持股60%，該公司股權價值中境內房地占70%；另一筆持股40%、房地占90%。是否視同房地交易？

```python
def 視同房地交易(持股比例, 房地占股權價值比例, 上市櫃興櫃=False):
    if 上市櫃興櫃:
        return False
    return 持股比例 > 50 and 房地占股權價值比例 >= 50   # 過半數；百分之五十以上

print("持股60%、房地70%：", 視同房地交易(60, 70))
print("持股40%、房地90%：", 視同房地交易(40, 90))
```
執行結果：
```text
持股60%、房地70%： True
持股40%、房地90%： False
```

## 常見誤解

- ❌「簽約日在105年以後就適用」→ 房屋、土地的取得日原則上看完成所有權移轉登記日（作業要點第四點）。
- ❌「農舍也適用房地合一」→ 第4項明文排除依農業發展條例申請興建之農舍。
