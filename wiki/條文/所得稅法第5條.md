# 所得稅法第5條（免稅額、課稅級距與累進稅率）

## 一句話重點

法律只寫「基準金額」和五級累進稅率（5%、12%、20%、30%、40%）；每年實際適用的免稅額和級距，要看財政部依物價指數計算後的公告。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 5 -->
> [!quote] 法條原文｜所得稅法第5條（版本 115-09-11）
> 綜合所得稅之免稅額，以每人全年六萬元為基準。免稅額每遇消費者物價指數較上次調整年度之指數上漲累計達百分之三以上時，按上漲程度調整之。調整金額以千元為單位，未達千元者按百元數四捨五入。
> 綜合所得稅課稅級距及累進稅率如下：
> 一、全年綜合所得淨額在五十二萬元以下者，課徵百分之五。
> 二、超過五十二萬元至一百十七萬元者，課徵二萬六千元，加超過五十二萬元部分之百分之十二。
> 三、超過一百十七萬元至二百三十五萬元者，課徵十萬零四千元，加超過一百十七萬元部分之百分之二十。
> 四、超過二百三十五萬元至四百四十萬元者，課徵三十四萬元，加超過二百三十五萬元部分之百分之三十。
> 五、超過四百四十萬元者，課徵九十五萬五千元，加超過四百四十萬元部分之百分之四十。
> 前項課稅級距之金額每遇消費者物價指數較上次調整年度之指數上漲累計達百分之三以上時，按上漲程度調整之。調整金額以萬元為單位，未達萬元者按千元數四捨五入。
> 綜合所得稅免稅額及課稅級距之金額，於每年度開始前，由財政部依據第一項及前項之規定計算後公告之。所稱消費者物價指數，指行政院主計總處公布至上年度十月底為止十二個月平均消費者物價指數。
> 營利事業所得稅起徵額及稅率如下：
> 一、營利事業全年課稅所得額在十二萬元以下者，免徵營利事業所得稅。
> 二、營利事業全年課稅所得額超過十二萬元者，就其全部課稅所得額課徵百分之二十。但其應納稅額不得超過營利事業課稅所得額超過十二萬元部分之半數。
> 三、營利事業全年課稅所得額超過十二萬元未逾五十萬元者，就其全部課稅所得額按下列規定稅率課徵，不適用前款規定。但其應納稅額不得超過營利事業課稅所得額超過十二萬元部分之半數：
> （一）一百零七年度稅率為百分之十八。
> （二）一百零八年度稅率為百分之十九。
<!-- /law -->

（第5項以下為營利事業所得稅，第一階段不討論。）

<!-- law: raw/A_法規/1150911_所得稅法.md | 5-1 -->
> [!quote] 法條原文｜所得稅法第5條之1（版本 115-09-11）
> 綜合所得稅之標準扣除額、薪資所得特別扣除額及身心障礙特別扣除額以第十七條規定之金額為基準，其計算調整方式，準用第五條第一項及第四項之規定。
> 前項扣除額及第五條免稅額之基準，應依所得水準及基本生活變動情形，每三年評估一次。

## 入門版

- 綜所稅是**累進稅率**：所得淨額越高，超過的那一段適用越高的稅率，共有5%、12%、20%、30%、40% 五級。
- 法條裡寫的「六萬元」「五十二萬元」是很多年前訂的基準。物價漲了，財政部就把金額調高，每年公告一次。
- 所以報稅時要看**當年度的公告**，不能看法條上的數字。115年度的金額見 [[綜合所得稅免稅額扣除額與課稅級距]]。

例外情形見進階版。

## 進階版

**條文結構**
- 第1項：免稅額基準每人全年六萬元；物價指數比上次調整年度上漲累計達3%以上時調整；以千元為單位，未達千元按百元數四捨五入。
- 第2項：五級課稅級距與稅率，以「課徵○元，加超過○元部分之○%」的方式表達。
- 第3項：級距金額同樣達3%即調整；以萬元為單位，未達萬元按千元數四捨五入。
- 第4項：每年度開始前由財政部計算後公告；「消費者物價指數」指行政院主計總處公布至上年度十月底為止十二個月平均。
- 第5條之1：標準扣除額、薪資所得特別扣除額、身心障礙特別扣除額以第17條金額為基準，準用相同的調整方式；扣除額與免稅額基準每三年評估一次。

**考點**
- 只有免稅額、級距、標準扣除額、薪資所得特別扣除額、身心障礙特別扣除額會隨物價調整。第17條的其他金額（例如房屋租金支出特別扣除每戶18萬元）不在第5條之1的範圍內。
- 速算公式的「累進差額」可以從級距和稅率推出來（見例題）。

## 計算例題

**入門題**：115年度，綜合所得淨額 500,000 元，應納稅額多少？（參數來源：[[綜合所得稅免稅額扣除額與課稅級距]]，115年度）

```python
淨額 = 500_000
# 115年度第1級：0～610,000，稅率5%，累進差額0
稅額 = 淨額 * 5 // 100 - 0
print(f"應納稅額：{稅額:,} 元")
```
執行結果：
```text
應納稅額：25,000 元
```

**進階題**：用第2項的「逐段累進」寫法，驗證115年度速算公式在淨額 2,000,000 元時結果相同。

```python
# 115年度級距（來源：[[綜合所得稅免稅額扣除額與課稅級距]]）
級距 = [(610_000, 5), (1_380_000, 12), (2_770_000, 20), (5_190_000, 30), (None, 40)]
淨額 = 2_000_000

# 方法一：逐段累進
稅額, 下限 = 0, 0
for 上限, 率 in 級距:
    段 = (min(淨額, 上限) if 上限 else 淨額) - 下限
    if 段 <= 0:
        break
    稅額 += 段 * 率 // 100
    下限 = 上限 if 上限 else 下限

# 方法二：速算公式（第3級：×20%－153,100）
速算 = 淨額 * 20 // 100 - 153_100
print(f"逐段累進：{稅額:,} 元；速算公式：{速算:,} 元；{'一致' if 稅額 == 速算 else '不一致'}")
```
執行結果：
```text
逐段累進：246,900 元；速算公式：246,900 元；一致
```

## 常見誤解

- ❌「免稅額是6萬元」→ 6萬元是法定基準；115年度一般免稅額是101,000元。
- ❌「所得淨額超過61萬元，全部都適用12%」→ 只有超過的那一段適用12%。
