# 所得稅法第14條之6（成交價額、成本、費用的核定）

## 一句話重點

沒申報或價格偏低，國稅局可依時價核定；沒有成本證明，可依查得資料或公告現值核定；沒有費用證明，按成交價額3%計算、最多30萬元。

## 條文

<!-- law: raw/A_法規/1150911_所得稅法.md | 14-6 -->
> [!quote] 法條原文｜所得稅法第14條之6（版本 115-09-11）
> 個人未依前條規定申報或申報之成交價額較時價偏低而無正當理由者，稽徵機關得依時價或查得資料，核定其成交價額；個人未提示原始取得成本之證明文件者，稽徵機關得依查得資料核定其成本，無查得資料，得依原始取得時房屋評定現值及公告土地現值按政府發布之消費者物價指數調整後，核定其成本；個人未提示因取得、改良及移轉而支付之費用者，稽徵機關得按成交價額百分之三計算其費用，並以三十萬元為限。
<!-- /law -->

## 入門版

- **賣價**：沒申報或申報得太低又沒有正當理由，國稅局會用市價或查到的資料來算。
- **買價（成本）**：拿不出買進的證明，國稅局可以用查到的資料；查不到，就用當年的房屋評定現值和公告土地現值按物價指數調整後計算。
- **費用**：拿不出費用單據，國稅局會直接用**成交價額的3%**算費用，但**最多30萬元**。

例外情形見進階版。

## 進階版

**作業要點的補充**

> [!info] 官方解釋｜房地合一課徵所得稅申報作業要點第十五點第三項（115年4月21日修正）
> 個人交易房屋、土地、房屋使用權未提示費用之證明文件或所提示之費用證明金額未達成交價額百分之三者，稽徵機關得按成交價額百分之三計算其費用，並以新臺幣三十萬元為限。但有藉分次交易房屋、土地部分持分或房屋使用權部分約定範圍之安排，規避或減少納稅義務者，以新臺幣三十萬元按該部分持分或約定範圍比例計算金額。

- 作業要點把「未提示」擴大到「提示的費用證明金額未達成交價額3%」也可以按3%計算。
- 第十一點：未依實際成交價額申報時，參酌金融機構貸款評定價格、不動產估價師估價、大型仲介公司資料、法拍價格等時價資料認定。
- 第十二點至第十四點：成本的認定方式。

**考點**：分次出售部分持分以規避30萬元上限者，上限按持分比例計算。

## 計算例題

**入門題**：成交價額 8,000,000 元與 15,000,000 元，兩案都沒有提示費用證明，國稅局各按多少計算費用？

```python
上限 = 300_000
for 成交價 in [8_000_000, 15_000_000]:
    費用 = min(成交價 * 3 // 100, 上限)
    print(f"成交價 {成交價:,} 元 → 費用 {費用:,} 元")
```
執行結果：
```text
成交價 8,000,000 元 → 費用 240,000 元
成交價 15,000,000 元 → 費用 300,000 元
```

**進階題**：成交價額 12,000,000 元，提示的費用證明只有 200,000 元。依作業要點第十五點，可按多少計算？

```python
成交價 = 12_000_000
提示費用 = 200_000
三趴 = 成交價 * 3 // 100
上限 = 300_000

if 提示費用 < 三趴:                 # 提示金額未達成交價額3%
    費用 = min(三趴, 上限)
else:
    費用 = 提示費用
print(f"成交價3% = {三趴:,}；提示 {提示費用:,} 未達3% → 按 {費用:,} 元計算")
```
執行結果：
```text
成交價3% = 360,000；提示 200,000 未達3% → 按 300,000 元計算
```

## 常見誤解

- ❌「費用一律可以扣成交價的3%」→ 3%是稽徵機關在缺乏或不足證明時「得」採用的計算方式，且上限30萬元。
- ❌「拆成幾次賣持分，每次都能用30萬元上限」→ 規避者按持分比例計算（作業要點第十五點）。
